# Estrutura de conversão BrinqueTEAndo

Este documento registra a arquitetura comercial aplicada à loja.

## Princípios

- Ensinar antes de vender: cada página orienta a escolha e reduz dúvidas.
- Oferta clara: benefício, público, uso, conteúdo, preço e CTA aparecem sem ambiguidade.
- Valor percebido: benefícios, modo de uso, itens incluídos e suporte são apresentados antes do preço.
- Funil: conteúdo educativo → descoberta por objetivo → produto → carrinho → recompra.
- Prova responsável: não usar avaliações, números, urgência ou escassez inventados.
- Catálogo centralizado: novos produtos alimentam automaticamente início, coleções, relacionados e ofertas.

## Regra operacional

Depois da implantação, a manutenção visual não deve ser necessária para inserir produtos. O cadastro deve conter os dados comerciais e pedagógicos do item; as páginas reutilizam esses dados automaticamente.
